# 2026-11-06 流量面板腳本審核

審核原則見 `AGENTS.md` 第 5 條。

## 採用：`modules/usage-panel.js`（自己寫的）

| 項目 | 內容 |
|---|---|
| 類型 | Surge `type=generic` 面板腳本，不是 MitM 腳本，不攔截、不改寫任何請求 |
| 讀什麼 | `$argument` 的 `url` 與 `token` 兩個參數 |
| 連到哪裡 | 只有 `url` 指定的一個網址，一次 GET，權杖放在 `Authorization` 標頭，不放網址 |
| 存什麼 | 什麼都不存：沒有 `$persistentStore`、沒有 `$notification`、沒有 `eval` 或動態產生程式碼 |
| 顯示什麼 | 回應裡每台節點一行：已用量、額度、重設日或起算日；錯誤時顯示一行簡短原因 |

- 介面網址與權杖只寫在私人設定檔的 `argument`，本倉庫不出現。
- 用 Node 的測試替身驗證：只發一個請求、權杖在標頭、401／404／429／連不上各有對應訊息、缺參數時不發請求、檔案裡沒有其他主機或儲存呼叫。4 項全過。
